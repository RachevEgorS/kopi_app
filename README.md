## Что работает

- Первый запуск → знакомство → регистрация или вход → бюджет текущего месяца → дневник.
- Валидация имени, почты, пароля и сумм; ошибки возле полей.
- Повторный запуск открывает дневник, после выхода открывается вход.
- Месяц по дате устройства; отдельные планы по месяцам; обновление даты при возвращении в приложение и во время работы приложения.
- Пропуск бюджета и изменение плана через «Профиль → Мой бюджет».
- Дневной ориентир, доход, расходы, шкала бюджета, дефицит и пустые состояния.
- История всех записей с поиском по названию, категории и дате, фильтры «Все / Расходы / Доходы». Фильтр и поиск сохраняются при возврате из редактирования.
- Полный экран операции: расход или доход, сумма, категория, заметка, дата. Создание, редактирование, удаление с подтверждением, защита от повторного сохранения. В новом плане доходы в пределах месячного плана подтверждают его, а превышение увеличивает бюджет. Выбирать способ учёта поступления в форме не нужно.
- Календарь с переключением месяца, выбором дня, точками платежей и списком на выбранную дату.
- Создание, редактирование и удаление платежей. Один раз или каждый месяц; если числа нет в месяце, платёж приходится на последний день (31 января → 28/29 февраля → 31 марта).
- Регулярные платежи с месячной суммой. Переходы из календаря и профиля. На Android доступны день и время напоминания до минуты, быстрые варианты и повтор через 15/30 минут, час или день. Для точного времени нужен системный доступ «Будильники и напоминания»; без него Android может задерживать доставку. Показ уведомлений также должен быть разрешён.
- Отметка «Оплачено» в день платежа или позже создаёт один связанный расход за сегодня и освобождает резерв. Удаление связанного расхода возвращает платёж в неоплаченные. Удаление плана не удаляет прошлые расходы.
- Нижняя навигация, системная кнопка «Назад», переходы из «Все записи», «Обязательные платежи», профиля и кнопки «+».
- Контекстные пояснения по «?» и «Профиль → Обучение и помощь».
- 96 значков для целей: поиск и шесть категорий. Выбранный значок сохраняется вместе с целью и отображается в списке и прогнозе. Старые значки совместимы.
- Обучающие карточки при первом посещении каждого из 15 экранов. Закрытие и «Теперь понятно» запоминают текущий экран; «Пропустить» отключает автоматические показы. Ручная помощь по «?» остаётся доступной. В профиле → «Обучение и помощь» можно снова включить подсказки.
- «Обзор»: диаграмма и доли категорий за выбранный месяц, раскрытие остальных категорий, сравнение с предыдущим периодом и переход к регулярным платежам. Доходы не попадают в диаграмму.
- «Мечты»: создание, изменение и удаление цели, сумма уже накопленного, недельный взнос и дата ближайшего взноса. Карточка открывает прогноз.
- Прогноз: интерактивный ползунок дополнительного недельного взноса; предварительный просмотр не изменяет данные. Подтверждение сохраняет новый темп и пересчитывает резерв дневника.
- Достижения: одна отметка проверки в день, серия календарных дней и три постоянных значка. Пропущенный день прерывает серию, уже полученные значки остаются.
- Профиль: редактирование имени и почты, переходы к бюджету, подпискам и достижениям, настройки напоминаний и мягких подсказок, помощь и выход. Бюджет возвращает в профиль после сохранения.
- Прокрутка и учёт клавиатуры. Проверены ширины 320, 360, 390 и 600 точек с масштабом текста 100% и 160%.

## Границы этапа

Вход, регистрация, подтверждение почты и восстановление пароля подключены к Supabase Auth. Финансовые данные хранятся в PostgreSQL: профили, бюджеты, операции, планы платежей и цели. Публичные настройки проекта находятся в `lib/data/cloud_config.dart`; обычный запуск F5 не требует дополнительных параметров. При возвращении в приложение данные обновляются; вручную — «Профиль → Уведомления и синхронизация → Обновить из аккаунта».

После первого входа финансовые данные доступны без сети. Изменения сохраняются вместе с очередью отправки, отдельно для каждого аккаунта; при открытом приложении синхронизация повторяется каждые 8 секунд и при возвращении в приложение. В целях доступны пополнение и история взносов; средства не переводятся автоматически. Приложение не переводит деньги и не отменяет подписки.

На Android добавлен модуль **Профиль → Уведомления и синхронизация → Уведомления банков**: отдельный системный доступ, выбор приложений и уведомления с кнопками «Добавить», «Изменить», «Пропустить». Подтверждённая запись сохраняется в локальной очереди и отправляется в фоне при наличии сети и действующей сессии. Для предложений нужно отдельно разрешить показ уведомлений. Чтение и автоматический импорт изначально выключены. Старые уведомления не читаются; сырой текст в облако не отправляется и удаляется после подтверждения. Подробности и ограничения — [инструкция](docs/notification-import.md).

Старый демодневник остаётся в `kopi.frontend.v1` и автоматически в аккаунт не переносится. Прогресс, достижения и состояние обучения сохраняются для аккаунта и синхронизируются с Supabase. Локальный кеш и очередь изменений разделены по ID аккаунта. Сессией управляет SDK Supabase; пароль приложение не сохраняет. Финансовое состояние очищается при выходе, навигация пересоздаётся при смене аккаунта.

Для подтверждения почты и сброса пароля в Supabase → Authentication → URL Configuration добавлен redirect `ru.kopi.finance://auth-callback`. Открывать ссылку восстановления нужно на устройстве, где она запрошена. Для web нужно отдельно разрешить точный адрес web-приложения. Уже применённые SQL-миграции повторно выполнять не требуется. Подробности — `supabase/README.md`.

## Расчёт

Деньги хранятся в целых копейках. Новый план содержит доход за месяц и сумму на мечты; кредит, аренда и подписки задаются отдельными платежами с датами. Это план расходования месячного дохода, включая ожидаемую зарплату, а не текущий остаток банковского счёта.

Средства нового плана — большая из двух сумм: доход плана или фактически записанные доходы месяца. Зарплата 60 000 ₽ при плане 60 000 ₽ не удваивает бюджет. Если сумма поступлений достигнет 65 000 ₽, бюджет увеличится до 65 000 ₽. Сохранённые старые планы используют прежний расчёт до пересохранения через «Мой бюджет».

Пусть `F` — свободная сумма после расходов, взносов в мечты и резервов, `S` — повседневные расходы сегодня, `D` — оставшиеся дни месяца, включая сегодня. Доступно сегодня: `max(0, (F + S) ~/ D − S)`. Поэтому сегодняшняя покупка уменьшает дневную сумму на всю стоимость покупки; на следующий день остаток распределяется заново. В расчёте также учитываются настройки переноса остатка и параметры старых планов.

Оплату обязательного платежа следует отмечать в календаре: связанный расход освобождает его резерв и не списывает сумму дважды. Для будущего месяца показан ориентир, для прошедшего — свободный остаток. Пример с 60 000 ₽ и подробности перехода со старого плана — [в описании расчёта](docs/simple-plan.md).

Резерв мечт — большая из сумм: ручной месячный резерв или сумма ближайших еженедельных взносов всех целей в оставшиеся дни выбранного месяца. Взносы ограничены остатком до цели; накопленные ранее деньги не списываются повторно. План без недельного взноса не обещает дату достижения. Прогноз округляет количество взносов вверх и учитывает дату ближайшего взноса.

Наблюдения для текущего месяца сравнивают одинаковое количество первых дней двух месяцев, ограниченное длиной предыдущего месяца. Для прошедших месяцев сравниваются полные месяцы. При отсутствии прошлых расходов процент роста не выдумывается.

Данные 18 200 ₽, цели и серия 7 дней в рендерах — тестовые примеры. Они не добавляются в пользовательский дневник.

## Запуск

Проверено с Flutter 3.47.7–3.47.8 / Dart 3.13.5–3.13.7. Inter и PT Serif включены в приложение, лицензии находятся в `assets/fonts/`. Новые тесты и сборка используют также SDK VS Code: `C:\Users\buratino\develop\flutter`.

```powershell
flutter pub get
flutter run
```

Браузер: `flutter run -d chrome`. Android APK: `flutter build apk --debug`, результат в `build/app/outputs/flutter-apk/app-debug.apk`. Это тестовая сборка. iOS-проект создан, но его сборка требует macOS/Xcode и здесь не проверялась.

### Релиз для тестирования на Android

Из корня проекта:

```powershell
.\tool\build-release.ps1
```

Скрипт использует Flutter из `$env:USERPROFILE\develop\flutter`, копирует исходники в каталог с латинским путём и запускает `flutter build apk --release`. Это обходит ошибку Android AOT при сборке из пути с кириллицей. APK находится в `$env:USERPROFILE\.codex\builds\kopi-release\build\app\outputs\flutter-apk\app-release.apk`.

Релизная сборка для тестирования использует текущую тестовую подпись. Для публикации в магазине потребуется настроить отдельный ключ подписи. Устанавливайте обновление с совместимой подписью поверх предыдущего приложения, сохраняя его данные.

Собранный браузерный просмотр: `node tool/serve-preview.cjs`, затем открыть http://127.0.0.1:4173. Сервер доступен только на этом компьютере.
