# Копи · мобильный интерфейс

Первый этап на Flutter: знакомство, вход, регистрация, бюджет месяца и основной «Дневник». Оформление по предоставленным макетам: тёплый фон, приглушённый розовый, тонкие иконки, заголовки с засечками. Синяя рамка редактора и нарисованный корпус телефона в приложение не перенесены; системные панели отображает устройство.

## Что работает

- Первый запуск → знакомство → регистрация или вход → бюджет текущего месяца → дневник.
- Валидация имени, почты, пароля и сумм; ошибки возле полей.
- Повторный запуск открывает дневник, после выхода открывается вход.
- Месяц по дате устройства; отдельные планы по месяцам; обновление даты при возвращении в приложение и каждые 30 секунд.
- Пропуск бюджета и изменение плана через «Профиль → Мой бюджет».
- Дневной ориентир, доход, расходы, шкала лимита, дефицит и пустые состояния.
- Форма добавления расхода: сумма, категория, заметка, дата. Защита от двойного сохранения. «Все записи» показывает расходы выбранного месяца.
- Контекстные пояснения по «?». «Профиль → Посмотреть пример дневника» показывает вымышленные расходы из макета отдельно от локальных записей.
- Прокрутка и учёт клавиатуры. Проверены ширины 320, 390 и 600 точек с масштабом текста 100% и 160%.

## Границы этапа

Вход и регистрация — **демонстрация интерфейса**, не аутентификация. Перед входом появляется пояснение. Пароли не сохраняются и не отправляются; восстановление не отправляет письма. На устройстве один демодневник: другая введённая почта не создаёт отдельный аккаунт. Supabase, облачная синхронизация и полноценная база операций пока не подключены.

«Календарь», «Мечты» и «Обзор» сохранены в нижней панели и открывают пояснение о следующем этапе. Уведомления и подписки пока не работают. Автоматическое обучение при первом посещении отложено; подсказки доступны по «?».

Локальное хранилище этапа — один JSON в `shared_preferences`, без паролей. Это временное хранилище прототипа. Для полноценного приложения необходимы серверная авторизация и транзакционная база операций.

## Расчёт

Деньги — целые копейки. `F = min(лимит − расходы, доступные деньги) − резерв платежей − резерв мечт`. Ориентир: `max(0, F ~/ оставшиеся дни)`, округление вниз до копейки.

В этом этапе «Доход за месяц» означает уже доступные деньги; ожидаемую зарплату вводить не нужно. Доступный остаток = доход − расходы. Резервы ещё не списаны, повторно из остатка не вычитаются. Для будущего месяца показан план на день, для прошедшего — свободный остаток. Значение 1 240 ₽ с макета не зафиксировано: сумма зависит от плана и даты.

В режиме примера расход 18 200 ₽ иллюстративный; видны три последние записи. Примеры не сохраняются в пользовательских записях.

## Запуск

Проверено с Flutter 3.47.8 / Dart 3.13.7. Inter и PT Serif включены в приложение, лицензии находятся в `assets/fonts/`.

```powershell
flutter pub get
flutter run
```

Браузер: `flutter run -d chrome`. Android APK: `flutter build apk --debug`, результат в `build/app/outputs/flutter-apk/app-debug.apk`. Это тестовая сборка. iOS-проект создан, но его сборка требует macOS/Xcode и здесь не проверялась.

На этом компьютере SDK находится в `C:\Users\buratino\.codex\tools\flutter`. Для обхода проблемы инструментов с длинным русским путём создана ссылка `C:\Users\buratino\.codex\projects\kopi-frontend` на эту же папку. Это не копия проекта. Команды проверки запускались из короткого пути. Для Android установлен `android.overridePathCheck=true`.

Собранный браузерный просмотр: `node tool/serve-preview.cjs`, затем открыть http://127.0.0.1:4173. Сервер доступен только на этом компьютере.

## Проверка и файлы

`flutter analyze` — статическая проверка. `flutter test` — расчёты, сохранение, первый запуск, добавление расхода, адаптация и рендеры экранов. Изображения тест сохраняет в `previews/`.

- `lib/main.dart` — первый запуск, переходы, дата устройства.
- `lib/data/diary.dart` — модели, расчёты, демохранилище.
- `lib/ui/design.dart` — палитра, типографика, иконки, поля и кнопки.
- `lib/ui/screens.dart` — пять экранов и вспомогательные панели.
- `test/` — тесты.
- `previews/` — изображения пяти экранов из Flutter.
