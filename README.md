# Копи · мобильный интерфейс

Версия 0.3.0 на Flutter: пятнадцать связанных экранов — знакомство, вход, регистрация, бюджет, дневник, история, операция, календарь, платёж, регулярные платежи, аналитика, мечты, прогноз цели, достижения и профиль. Оформление по предоставленным макетам: тёплый фон, приглушённый розовый, тонкие иконки, заголовки с засечками. Синяя рамка редактора и нарисованный корпус телефона в приложение не перенесены; системные панели отображает устройство.

## Что работает

- Первый запуск → знакомство → регистрация или вход → бюджет текущего месяца → дневник.
- Валидация имени, почты, пароля и сумм; ошибки возле полей.
- Повторный запуск открывает дневник, после выхода открывается вход.
- Месяц по дате устройства; отдельные планы по месяцам; обновление даты при возвращении в приложение и каждые 30 секунд.
- Пропуск бюджета и изменение плана через «Профиль → Мой бюджет».
- Дневной ориентир, доход, расходы, шкала лимита, дефицит и пустые состояния.
- История всех записей с поиском по названию, категории и дате, фильтры «Все / Расходы / Доходы». Фильтр и поиск сохраняются при возврате из редактирования.
- Полный экран операции: расход или доход, сумма, категория, заметка, дата. Создание, редактирование, удаление с подтверждением, защита от повторного сохранения. Доходы увеличивают доступные средства и не учитываются как расходы.
- Календарь с переключением месяца, выбором дня, точками платежей и списком на выбранную дату.
- Создание, редактирование и удаление платежей. Один раз или каждый месяц; если числа нет в месяце, платёж приходится на последний день (31 января → 28/29 февраля → 31 марта).
- Регулярные платежи с месячной суммой. Переходы из календаря и профиля. Настройка напоминания сохраняется локально.
- Отметка «Оплачено» в день платежа или позже создаёт один связанный расход за сегодня и освобождает резерв. Удаление связанного расхода возвращает платёж в неоплаченные. Удаление плана не удаляет прошлые расходы.
- Нижняя навигация, системная кнопка «Назад», переходы из «Все записи», «Скоро», профиля и кнопки «+».
- Контекстные пояснения по «?» и «Профиль → Обучение и помощь».
- «Обзор»: диаграмма и доли категорий за выбранный месяц, раскрытие остальных категорий, сравнение с предыдущим периодом и переход к регулярным платежам. Доходы не попадают в диаграмму.
- «Мечты»: создание, изменение и удаление цели, сумма уже накопленного, недельный взнос и дата ближайшего взноса. Карточка открывает прогноз.
- Прогноз: интерактивный ползунок дополнительного недельного взноса; предварительный просмотр не изменяет данные. Подтверждение сохраняет новый темп и пересчитывает резерв дневника.
- Достижения: одна отметка проверки в день, серия календарных дней и три постоянных значка. Пропущенный день прерывает серию, уже полученные значки остаются.
- Профиль: редактирование имени и почты, переходы к бюджету, подпискам и достижениям, настройки демонстрационных напоминаний и мягких подсказок, помощь и выход. Бюджет возвращает в профиль после сохранения.
- Прокрутка и учёт клавиатуры. Проверены ширины 320, 390 и 600 точек с масштабом текста 100% и 160%.

## Границы этапа

Вход и регистрация — **демонстрация интерфейса**, не аутентификация. Перед входом появляется пояснение. Пароли не сохраняются и не отправляются; восстановление не отправляет письма. На устройстве один демодневник: другая введённая почта не создаёт отдельный аккаунт. Supabase, облачная синхронизация и полноценная база операций пока не подключены.

Все экраны работают локально. Сумму «Уже накоплено» пользователь обновляет вручную: автопополнений и банковских переводов нет. Настройка напоминания пока не отправляет уведомления. Приложение не переводит деньги и не отменяет подписки. Автоматическое обучение при первом посещении отложено; подсказки доступны по «?».

Локальное хранилище этапа — один JSON в `shared_preferences`, без паролей. Это временное хранилище прототипа. Для полноценного приложения необходимы серверная авторизация и транзакционная база операций.

## Расчёт

Деньги — целые копейки. `F = min(лимит − расходы, доступные деньги) − резерв платежей − резерв мечт`. Ориентир: `max(0, F ~/ оставшиеся дни)`, округление вниз до копейки.

В этом этапе доход месячного плана означает уже доступные деньги; ожидаемую зарплату вводить не нужно. Новые операции дохода — дополнительные поступления сверх этой суммы. Доступный остаток = доход плана + новые доходы − расходы. Резерв платежей равен большей из сумм: оставшийся ручной резерв или неоплаченные планы месяца. Оплаченные связанные расходы уменьшают ручной резерв, поэтому платёж не вычитается дважды. Для будущего месяца показан план на день, для прошедшего — свободный остаток. Значение 1 240 ₽ с макета не зафиксировано: сумма зависит от плана и даты.

Резерв мечт — большая из сумм: ручной месячный резерв или сумма ближайших еженедельных взносов всех целей в оставшиеся дни выбранного месяца. Взносы ограничены остатком до цели; накопленные ранее деньги не списываются повторно. План без недельного взноса не обещает дату достижения. Прогноз округляет количество взносов вверх и учитывает дату ближайшего взноса.

Наблюдения для текущего месяца сравнивают одинаковое количество первых дней двух месяцев, ограниченное длиной предыдущего месяца. Для прошедших месяцев сравниваются полные месяцы. При отсутствии прошлых расходов процент роста не выдумывается.

Данные 18 200 ₽, цели и серия 7 дней в рендерах — тестовые примеры. Они не добавляются в пользовательский дневник.

Проверено с Flutter 3.47.7–3.47.8 / Dart 3.13.5–3.13.7. Inter и PT Serif включены в приложение, лицензии находятся в `assets/fonts/`. Новые тесты и сборка используют также SDK VS Code: `C:\Users\buratino\develop\flutter`.

```powershell
flutter pub get
flutter run
```

Браузер: `flutter run -d chrome`. Android APK: `flutter build apk --debug`, результат в `build/app/outputs/flutter-apk/app-debug.apk`. Это тестовая сборка. iOS-проект создан, но его сборка требует macOS/Xcode и здесь не проверялась.

На этом компьютере SDK находится в `C:\Users\buratino\.codex\tools\flutter`. Для обхода проблемы инструментов с длинным русским путём создана ссылка `C:\Users\buratino\.codex\projects\kopi-frontend` на эту же папку. Это не копия проекта. Команды проверки запускались из короткого пути. Для Android установлен `android.overridePathCheck=true`.

Собранный браузерный просмотр: `node tool/serve-preview.cjs`, затем открыть http://127.0.0.1:4173. Сервер доступен только на этом компьютере.

## Проверка и файлы

`flutter analyze` — статическая проверка. `flutter test` — расчёты, сохранение, первый запуск, добавление расхода, адаптация и рендеры экранов. Изображения тест сохраняет в `previews/`.

- `lib/main.dart` — первый запуск, переходы, дата устройства.
- `lib/data/diary.dart` — модели, расчёты, демохранилище.
- `lib/ui/design.dart` — палитра, типографика, иконки, поля и кнопки.
- `lib/ui/screens.dart` — пять экранов и вспомогательные панели.
- `lib/ui/finance_flow.dart` — навигация новых экранов, возврат и профиль.
- `lib/ui/finance_pages.dart` — история, операция, календарь, платёж и подписки.
- `lib/data/progress.dart` — аналитика, прогнозы, календарные серии и резерв целей.
- `lib/ui/progress_pages.dart` — аналитика, мечты, прогноз, достижения, профиль и формы редактирования.
- `lib/ui/finance_widgets.dart` — общие элементы финансовых экранов.
- `test/` — тесты.
- `previews/` — изображения пятнадцати экранов из Flutter. Демоданные используются только тестами и режимом примера, не добавляются в пользовательский дневник.
