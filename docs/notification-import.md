# Уведомления банков · Android

Открой **Профиль → Уведомления банков** после входа в аккаунт.

1. Нажми «Открыть настройки Android» и самостоятельно разреши доступ для Копи.
2. Вернись в приложение, выбери установленные банковские приложения.
3. Включи «Читать выбранные приложения».
4. Новые сообщения появятся в очереди. Проверь сумму и нажми «Добавить в дневник».
5. По желанию включи «Добавлять автоматически». Пока Копи открыто, проверка идёт каждые 8 секунд.

Системный доступ и оба переключателя не включаются автоматически. Фоновая служба Android
собирает новые уведомления даже без открытого Flutter-экрана; запись в Supabase происходит
только при открытом приложении, активном аккаунте и доступной сети. После принудительной
остановки приложения системой/пользователем доставка может прекратиться до нового запуска.

Распознаются однозначные рублёвые покупки, списания, зачисления и возвраты. Из суммы
исключается остаток/баланс. Реклама, коды, отказы, будущие платежи, сообщения с несколькими
суммами и неподдерживаемой валютой не записываются автоматически. Неизвестные форматы
остаются для ручной проверки/пропуска; операцию можно добавить обычной кнопкой «+».
Распознанную операцию можно изменить в истории. Форматы конкретных банков на реальных
телефонах ещё нужно проверить; универсальная совместимость не гарантируется.

Копи не получает доступ к банковскому аккаунту, SMS или истории операций. Если Android
или банк скрывает содержимое уведомления, распознать сумму невозможно. Старые активные
уведомления при подключении службы не сканируются. iOS и браузер не поддерживаются.

## Данные и повторы

- Только выбранные пакеты приложений; групповые сводки, постоянные уведомления и коды отбрасываются.
- Локальная очередь: максимум 200 сообщений. Старше 48 часов удаляются при следующем обращении к очереди.
- Выключение чтения, выход/смена аккаунта очищают очередь; удаление приложения из выбора удаляет его ожидающие сообщения.
- Резервное копирование Android отключено. Полный текст не логируется и не отправляется в Supabase.
- В `transactions` сохраняются сумма в копейках, вид, категория, нейтральное название, дата,
  `source=notification` и хеш события в `source_ref`. Имя магазина из произвольного текста не выгружается.
- ID операции детерминирован по аккаунту и событию. Повтор запроса после сбоя использует тот же ID;
  очередь подтверждается только после записи в базу. Защита от дубликатов работает для одного
  идентификатора/времени уведомления Android; два разных уведомления об одной банковской операции
  могут потребовать ручного удаления дубля. Сверки с историей банка нет.
- Переводы между своими счетами и уже внесённую вручную зарплату нужно проверять отдельно,
  чтобы не учитывать один доход дважды. По умолчанию автоматическое добавление выключено.

SQL из предыдущего этапа менять не требуется. Дополнительных облачных ключей нет.
Модуль не получает и не хранит пароль пользователя.

Проверка: тесты парсера (включая коды, баланс, неподдерживаемые суммы), HTTP-тест импорта
с повтором, ошибкой записи и чужим владельцем; общие тесты приложения. Android-сборка
проверяется отдельно. Системное разрешение за пользователя не выдаётся.

Основа: [Android NotificationListenerService](https://developer.android.com/reference/android/service/notification/NotificationListenerService).
